## Что показывают команды Git

`git add` подготавливает изменения к сохранению, `git commit` сохраняет их в истории.
Ветка `feature` позволяет разрабатывать дополнение отдельно от `main`.
Pull Request показывает предлагаемые изменения перед объединением веток.
Merge-коммит сохраняет связь обеих веток. Тег `v1.0.0` отмечает версию работы.
`git push` отправляет локальные коммиты, ветки и теги на GitHub.
