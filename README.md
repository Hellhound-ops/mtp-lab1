## О проекте

Небольшая консольная программа на Python. Выводит сведения об авторе
и пять заданий варианта 3.
Дополнительная функциональность разрабатывается в ветке `feature`.
Внешние библиотеки не требуются.

## Запуск

```console
python main.py
python study_plan.py
```

## Задания варианта 3

| Уровень | Номер | Задание |
| --- | --- | --- |
| Средний | 3 | Добавить файл и сделать коммит |
| Средний | 5 | Создать ветку feature и добавить новый файл |
| Средний | 9 | Отправить изменения на GitHub |
| Повышенный | 3 | Создать Pull Request |
| Повышенный | 7 | Создать релиз (tag) на GitHub |

## Проверка истории

```console
git log --all --graph --oneline --decorate
git show feature:study_plan.py
git tag -n
```

Первый коммит добавляет `main.py`. Новый файл `study_plan.py` добавляется
отдельным коммитом в ветке `feature`. История сохраняет эти действия.

Публикация, Pull Request и релиз оформляются на GitHub после загрузки веток.
